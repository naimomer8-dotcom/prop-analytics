🚀 מדריך הגדרה — Google Apps Script
1
צור Google Sheet חדש
פתח sheets.new ותן שם כמו "PropAnalytics".
2
פתח Apps Script
בגיליון: Extensions → Apps Script. מחק הכל והדבק את הקוד הבא:
טוען...
3
שנה את ה-SECRET KEY
בשורה הראשונה בקוד שנה 'CHANGE_THIS_SECRET' לסיסמה שלך. אותה סיסמה תזין למעלה ב-"Secret Key".
4
פרוס כ-Web App
לחץ Deploy → New deployment → Web app.
• Execute as: Me
• Who has access: Anyone
לחץ Deploy, אשר הרשאות, והעתק את ה-URL.
5
הכנס את הפרטים למעלה
הדבק את ה-Web App URL, הזן את ה-Secret Key, והזן את ה-URL של המחשבון שהעלאת לאינטרנט. לחץ "שמור הגדרות".
